# Les zones de contrôle d'Ephor — LA liste qui fait foi, dans le moteur.
#
# Ce que l'agent n'écrit jamais : ses propres consignes et garde-fous, la CI, le juge, les
# contrats, et, sur le poste, les réglages des agents eux-mêmes. Elle alimente le juge,
# les gardes (édition et terminal), la sentinelle et la garde des contrôles de la CI.
#
# Pourquoi ici, et pas dans .claude/settings.json : une défense ne lit pas sa politique dans
# un fichier que l'agent peut écrire. Mesuré le 25/09/2026 : la sentinelle lisait ses zones
# dans les réglages, et un agent qui en retirait une règle la rendait aveugle. Les réglages
# du projet peuvent AJOUTER des zones (leurs refus Edit(...)) ; ils ne peuvent pas en retirer.
#
# Forme : une entrée par ligne. « x/ » : ce dossier et tout ce qu'il contient ; « x » : ce
# fichier. Relatif : dans le dépôt. « ~/ » : sur le poste, hors de tout dépôt. « ! » en tête :
# exception, pour le poste seulement.
