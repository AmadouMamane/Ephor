# Fiches de composant

Une fiche par composant qui mérite d'être expliqué, sur le modèle de `TEMPLATE.md`.
Elles ne sont chargées qu'à la demande : elles ne coûtent rien tant qu'on ne les ouvre pas.

Quand en écrire une : le composant a déjà surpris quelqu'un, ou il a des invariants que le
code ne dit pas. Sinon, la carte du code (`make map`) suffit.
